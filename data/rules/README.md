Сюда кладутся тексты грамматических правил: по одному файлу на правило,
имя файла — идентификатор правила из `rules.json` плюс `.md`.

Для первой фазы нужны четыре:

- `alphabet.md` — Алфавит и чтение
- `artikel.md` — Существительные, артикли и большая буква
- `sein.md` — Я есть, ты есть, вы есть
- `wortfolge.md` — Порядок слов в простом предложении и вопрос

Пока файла нет, на экране стоит спокойная строка «Текст правила пока не написан».
Это нормальное состояние, а не ошибка.

Разметка самая простая: заголовки через `#`, списки через `-`, жирный через
`**жирный**`, таблицы через `|`. Падежи называть по-человечески, вопросами,
а термин в скобках рядом.
