# Кого? Что? — слово рядом с глаголом тоже меняется

В предложении обычно есть тот, кто делает действие, и часто есть ещё
кто-то или что-то, с чем это действие происходит — то, что отвечает на
вопрос «кого? что?». В немецком у этого второго слова иногда меняется
артикль.

# Меняется только мужской род

Вот в чём вся хитрость: артикль меняется ТОЛЬКО у слов мужского рода.
У женского, среднего и множественного числа — всё как обычно, без
изменений.

| Род | Кто? Что? (как обычно) | Кого? Что? (рядом с глаголом) |
|---|---|---|
| мужской | der Schlüssel / ein Bruder | den Schlüssel / einen Bruder |
| женский | die Schwester / eine Tasche | die Schwester / eine Tasche |
| средний | das Kleid / ein Kissen | das Kleid / ein Kissen |
| множественное | die Schuhe | die Schuhe |

У мужского рода: der → den, ein → einen. Больше ничего запоминать не
нужно — у остальных трёх строчек в таблице ничего не меняется.

# Примеры

| По-немецки | По-русски |
|---|---|
| Ich habe einen Bruder. | У меня есть брат. |
| Ich nehme den Kuchen. | Я беру пирог. |
| Ich habe eine Schwester. | У меня есть сестра. |
| Ich habe ein Kissen. | У меня есть подушка. |

Во второй строке видно: Kuchen — мужского рода (der Kuchen), и рядом с
глаголом nehme он стал den Kuchen.

# Ты уже это видел

В Городе в сценке про срочный вызов есть фраза «Ich brauche einen Arzt»
— врач, der Arzt, мужского рода, и рядом с brauche он стал einen Arzt.
Теперь понятно, откуда взялась эта форма.

# Интересно

- В русском похожая идея есть у одушевлённых слов мужского рода: «вижу
  брата» (не «брат»), а у неодушевлённых и у слов других родов часто
  никаких изменений нет: «вижу стол», «вижу сестру». В немецком же дело
  не в одушевлённости, а именно в роде.
- Эта же схема (меняется только мужской род) будет повторяться в
  немецком ещё не раз — полезно запомнить её один раз и хорошо.
