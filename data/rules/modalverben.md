# Глаголы про «должен», «могу», «хочу»

Эти глаголы не называют само действие, а говорят об отношении к нему:
должен ли ты, можешь ли, хочешь ли. Рядом с ними почти всегда стоит ещё
один глагол — в своей словарной форме, в самом конце простого
предложения.

# müssen: должен

| Кто | müssen | Как читается |
|---|---|---|
| ich | muss | мус |
| du | musst | муст |
| er / sie / es | muss | мус |
| wir | müssen | мЮсен |
| ihr | müsst | мюст |
| sie / Sie | müssen | мЮсен |

Заметь: у ich и у er/sie/es — одинаковая форма, muss. Так и должно быть,
окончания здесь вообще нет. Это касается всех глаголов на этой странице.

# können: могу

| Кто | können | Как читается |
|---|---|---|
| ich | kann | кан |
| du | kannst | канст |
| er / sie / es | kann | кан |
| wir | können | кЁнен |
| ihr | könnt | кёнт |
| sie / Sie | können | кЁнен |

Та же картина: ich и er — одинаково, kann. А во wir/ihr/sie гласная
меняется назад на ö — такое поведение тоже общее для всех этих глаголов.

# Остальные коротко

| Глагол | Я (ich) | Значение |
|---|---|---|
| wollen | ich will | хочу |
| sollen | ich soll | должен (кто-то так велел) |
| dürfen | ich darf | мне можно, разрешено |

У всех у них — та же картина: ich и er совпадают, окончания нет.

# Особый случай: möchten

möchten — вежливое «хотел бы». Ведёт себя немного по-другому: у него
есть окончания, но зато ich и er тоже совпадают.

| Кто | möchten |
|---|---|
| ich | möchte |
| du | möchtest |
| er / sie / es | möchte |
| wir | möchten |
| ihr | möchtet |
| sie / Sie | möchten |

# Примеры

| По-немецки | По-русски |
|---|---|
| Ich muss schlafen. | Мне нужно спать. |
| Ich kann helfen. | Я могу помочь. |
| Ich möchte eine Tablette. | Я хотел бы таблетку. |

В первых двух примерах виден порядок: модальный глагол — второй, а
обычный глагол (schlafen, helfen) — в самом конце.

# Интересно

- möchten на самом деле — вежливая форма от другого глагола, mögen
  (нравиться). Получается, «я хотел бы» по-немецки буквально ближе к «мне
  бы понравилось».
- Такая же схема, где ich и er совпадают, есть в английском только у
  modal-глаголов: I can, he can — тоже без отдельного окончания. В
  обычных глаголах такого нет (I speak, но he speaks).
