# Чьё это: mein, dein, sein...

Чтобы сказать «мой, твой, его...», в немецком есть своё слово под каждое
«я/ты/он...» — так же, как было со словом sein.

| Кто | Чей/чья/чьё |
|---|---|
| ich | mein |
| du | dein |
| er | sein |
| sie | ihr |
| es | sein |
| wir | unser |
| ihr | euer |
| sie | ihr |
| Sie | Ihr |

# Окончание меняется от рода слова рядом

Сами эти слова (mein, dein...) ведут себя как уже знакомое kein: перед
словом мужского и среднего рода — без окончания, перед словом женского
рода и во множественном числе — добавляется -e.

| Род слова рядом | Например |
|---|---|
| мужской | mein Kopf |
| средний | mein Auge |
| женский | meine Nase |
| множественное | meine Augen |

# Примеры

| По-немецки | По-русски |
|---|---|
| Mein Kopf tut weh. | У меня болит голова. |
| Deine Nase ist rot. | Твой нос красный. |
| Sein Bauch tut weh. | У него болит живот. |
| Ihre Hand ist klein. | Её рука маленькая. |

# Маленькая ловушка

ihr может значить и «вы» (несколько человек), и «её». А ещё есть похожее
слово euer — «ваш» (несколько человек). Это разные слова, просто похожи
по звучанию — путаница такая же, как с sie/Sie из правила про sein.

# Интересно

- Mein, dein, sein и остальные — родственники английских my, your, his:
  когда-то давно это были одни и те же слова, просто языки разошлись.
- У euer есть небольшая особенность: когда добавляется окончание -e,
  средняя буква e пропадает — получается eure, а не euere. Это редкое
  исключение, достаточно просто его узнавать, когда встретится.
